# 房地稅費與貸款試算：品牌顧問風分步改版設計

日期：2026-07-31

## 目標

將主頁四個計算器改成使用者已選定的 B「品牌顧問風」：

- 視覺採暖米白、深海軍藍、陶土橘與低彩度灰綠。
- 保留台南小魏照片，但縮成上方品牌識別，不再占滿手機首屏。
- 手機版改成清楚的分步式操作，降低一次看到大量欄位的壓力。
- 桌機版保留高效率的表單與即時結果雙欄，不強迫逐步點選。
- 保留所有公式、政策數字、免責聲明、政府來源、LIFF 好友鎖、網址 hash 與 localStorage。

本次處理 `index.html` 主頁。`tainan-land-value-helper.html` 與
`land-increment-total.html` 維持既有功能與外觀，避免把主頁改版擴張成三個獨立工具的重寫。

## 品牌視覺

### 配色

```css
--consultant-cream: #f3ead7;
--consultant-paper: #fffaf0;
--consultant-navy: #102738;
--consultant-navy-strong: #0b1f2c;
--consultant-terracotta: #b9502d;
--consultant-terracotta-dark: #943e26;
--consultant-olive: #657244;
--consultant-ink: #24231f;
--consultant-muted: #6d695f;
--consultant-line: #d7cdbb;
```

- 米白承載頁面與卡片，深藍建立專業顧問感。
- 陶土橘只用於作用中分頁、主要按鈕、進度與重要數字。
- 灰綠只作為輔助狀態色，不與成功、警告、錯誤語意色混用。
- 移除厚重漸層、金色發光與大面積玻璃效果。

### 字體與層級

- 主標題與重要區塊標題使用現有襯線字體堆疊。
- 表單、按鈕、說明與數字使用黑體字體堆疊。
- 手機主標題約 28–32px，結果主數字約 30–38px。
- 使用字重、細線與留白建立層級，不依賴裝飾性陰影。

### 元件

- 主卡片圓角 12px，輸入框與按鈕圓角 8–10px。
- 卡片使用細邊框與短距離低透明陰影。
- 所有觸控操作高度至少 44px。
- Focus 狀態使用清楚的陶土橘外框，並保留 `prefers-reduced-motion`。

## 頁首與導覽

### 品牌頁首

- 桌機高度控制在約 176–188px，左側為品牌、標題與免責提醒，右側為縮小人物照。
- 手機高度控制在約 144–160px，人物照縮到右上或右下，不遮擋標題。
- 顯示「台南小魏 買厝作伙」、魏泉承、任職店別與電話。
- 資料校訂日期保留為可維護 HTML，不烙在圖片內。
- 不新增純視覺型進場遮罩；現有 LIFF 開啟來源與好友檢查流程維持不變。

### 四個計算器分頁

- 桌機維持四等分分頁。
- 手機使用可橫向滑動的緊湊分頁列。
- 作用中分頁為陶土橘底白字，其餘為暖白底深藍字。
- 切換分頁時維持既有 `#tax`、`#buyer`、`#loan`、`#young` hash。

## 手機分步流程

### 共通規則

- 僅在 `620px` 以下啟用分步介面；桌機與平板顯示完整表單。
- 每個計算器顯示 `01 / 04` 形式的進度、短標題與進度條。
- 同一時間只顯示目前步驟內容；上一步、下一步固定放在該步驟下方。
- 最後一步顯示完整試算結果、複製結果、存成圖片與重新調整按鈕。
- 下一步只阻擋目前步驟中格式錯誤或超出既有限制的欄位，不新增政策判定或公式規則。
- 切換分頁時回到該計算器第一步；旋轉或切回桌機不遺失輸入。
- 步驟狀態只存在目前頁面，不加入 URL，避免破壞既有分享連結。
- Back/Next 按鈕與進度使用可存取標籤；鍵盤焦點在換步後移到步驟標題。

### 房地合一稅

1. 成交資料：出售價格、取得成本、持有期間。
2. 可扣除項目：出售費用、土地漲價總數額等既有欄位。
3. 適用條件：自住與既有稅率／資格選擇。
4. 試算結果：應納稅額、稅率、計算明細與操作按鈕。

### 買方費用

1. 購屋條件：成交總價、貸款成數、自備款。
2. 稅費基礎：房屋評定現值、土地申報地價與抵押權設定。
3. 其他費用：代書、簽約、銀行、保險與既有雜費。
4. 準備金結果：現金需求、費用明細、提醒與操作按鈕。

### 一般貸款

1. 貸款目標：成交總價、貸款成數、貸款額、自備款。
2. 貸款條件：利率、年限、寬限期。
3. 還款設定：本息／本金平均、額外還款與既有選項。
4. 月付結果：寬限期月付、正常月付、利息與攤還明細。

### 青安貸款 3.0

1. 資格快篩：無自有住宅、自住、限貸一次、年齡與所得。
2. 購屋與貸款：房價、區域上限、成數、自備款與額度類型。
3. 負擔評估：寬限期、家庭可支配收入與既有快速選擇。
4. 青安結果：資格、額度、分期補貼、月付與負擔比結果。

## 桌機與平板

- `901px` 以上維持左表單、右結果，比例約 `58% / 42%`。
- `621px–900px` 改為單欄，但仍一次顯示完整表單與結果。
- 桌機不顯示步驟導覽，避免增加原本快速試算的點擊次數。
- 表單與結果卡片使用同一套米白、深藍與陶土橘視覺。
- 結果欄在可用高度內使用黏附定位；空間不足時回到正常文件流。

## 程式實作

- 維持單一 `index.html`，不加入框架、CSS library 或 CDN。
- 在現有最末端主題後新增「Consultant B」覆寫層，避免大規模刪改既有樣式。
- 為現有欄位區塊補上步驟容器或 `data-wizard-step` 標記，不改輸入欄位 ID。
- 新增小型 wizard controller，負責目前步驟、按鈕、進度與 focus。
- 現有計算、localStorage、hash 切換、清空、複製、圖片輸出及 LIFF 程式保持原介面。
- 若既有清空或切換分頁會重設畫面，wizard controller 同步回到第一步。

## 錯誤與空狀態

- 欄位錯誤顯示在欄位附近，並將焦點移到第一個錯誤欄位。
- 未完成有效輸入時，結果保留既有空狀態，不顯示虛構數字。
- 成功、警告、錯誤仍使用語意色與文字，不能只靠顏色。
- 圖片輸出失敗、剪貼簿失敗與外部查詢失敗沿用既有錯誤處理。

## 測試與驗收

1. 既有 Node 測試全部通過。
2. 新增 B 主題、四個 wizard、進度與導覽按鈕的結構測試。
3. 四個計算器在桌機與手機都能產生結果。
4. 清空、套用範例、複製結果、存成圖片功能維持可用。
5. 手機 `375×812` 與 `390×844` 無水平溢位、按鈕重疊或內容截斷。
6. 桌機 `1280×800` 可直接看到分頁與主要輸入區。
7. 切換分頁、上一步、下一步及重新調整不遺失資料。
8. 人物照片頭部不裁切，且不遮擋品牌文字。
9. Console 無 JavaScript 錯誤。
10. GitHub Pages 部署完成後，用新的 `?v=` 參數驗證 `#tax`、`#buyer`、`#loan`、`#young`。

## 不變更事項

- 不改稅率、免稅額、政策數字、貸款公式或政府來源。
- 買方仲介服務費維持成交總價 2%。
- 不刪除免責聲明、品牌聯絡資訊或 LIFF 好友鎖。
- 不更換、生成或修圖人物照片。
- 不新增後端、帳號系統或外部分析工具。
