# 貸款結果資訊降壓與購屋預算跑道設計規格

日期：2026-08-02
狀態：已完成對話設計確認，待使用者審閱書面規格

## 目標

調整「貸款計算」與「青安貸款 3.0」結果頁的資訊層級，讓買方先看到每月負擔、房價與自備款，再自行展開長期利息資訊。貸款結果頁新增可互動的「購屋預算跑道」，把第 3 步的收入回推結果移到最後一頁，並統一四個計算器的精靈導覽按鈕。

## 使用者需求

1. 利息資訊不可在主結果頁以大額數字或主要表格欄位直接搶焦點。
2. 利息仍需保留，預設收合在「查看總成本明細」中，維持試算透明度。
3. 一般貸款結果不再重複顯示最高月付與最低月付；沒有寬限期時只保留一個主要「每月月付」。
4. 「用薪水回推能買多少」的結果要用有趣、可互動的方式放在最後一頁。
5. 所有精靈最後一頁的「重新調整」改成「上一頁」。
6. 上一步與下一步同時存在時必須等寬、等高並對齊。

## 非目標

- 不改變貸款本金、利率、年限、月付、青安五階段利率或資格判斷公式。
- 不刪除利息資料，也不隱瞞長期總成本。
- 不把結果頁的收入模擬值套回貸款本金或月付結果；它只影響可負擔房價跑道。
- 不改變「重新試算」的清除資料功能。

## 結果頁資訊層級

### 一般貸款

結果由上到下排列：

1. 主要月付卡。
   - 沒有寬限期：只顯示一個「每月月付」。
   - 有寬限期：保留「寬限期月付」與「寬限期後月付」，因兩者代表不同階段而非重複資訊。
2. 自備款與貸款摘要。
   - 房屋成交總價。
   - 貸款本金。
   - 實際貸款成數。
3. 購屋預算跑道。
4. 攤還期數與主要攤還表。
5. 預設收合的「查看總成本明細」。
6. 複製結果、存成圖片、重新試算。

現有「總利息與月付範圍」主卡移除。其「最高月付」與「最低月付」列一併移除，避免和頁首月付重複。還款總額改放到收合的總成本明細。

### 青安貸款 3.0

保留已核准的主要層級：

1. 購屋總價、預估總貸款、預估自備款三卡。
2. 補充貸款說明滿版置於三卡下方。
3. 寬限期與寬限期後月付。
4. 貸款金額組成、貸款年限、建議家庭收入、收入占比。
5. 青安五階段利率與月付表。
6. 資格檢核。
7. 預設收合的「查看總成本明細」。

主畫面移除「40 年預估總利息」列。五階段表格的主表移除「利息」欄，只保留階段、年利率、月付與本金餘額。

## 利息與總成本明細

一般貸款與青安結果各自使用原生 `<details>`／`<summary>` 元件建立「查看總成本明細」，預設為收合狀態。

### 一般貸款明細內容

- 預估總利息。
- 預估還款總額。
- 各攤還區間的支付利息。
- 說明文字：「此為完整貸款期間累計估算，實際金額仍以銀行核定與後續利率調整為準。」

主攤還表移除「支付利息」欄，只保留期數區間、月付範圍、償還本金與期末本金餘額。各區間利息改放在總成本明細中。

### 青安明細內容

- 依目前貸款年限計算的預估總利息。
- 五階段各階段利息。
- 說明文字：「此為完整貸款期間累計估算，實際利率、補貼與核貸條件仍以承貸銀行為準。」

## 購屋預算跑道

採用使用者核准的 A 方案「購屋預算跑道」。

### 顯示內容

- 標題：「你的舒適購屋帶」。
- 依家庭月收入、自備款、目前利率與年限計算的房價區間。
- 三個視覺區域：安心、剛好、挑戰。
- 「本次房價」標記，顯示目前輸入房價落在哪個區域。
- 建議每月房貸範圍。
- 一句依區域變化的友善說明，不使用恐嚇或勸退語氣。

### 區域判斷

- 安心：本次房價低於以月收入三分之一月付推算的房價下界。
- 剛好：本次房價介於月收入三分之一～40% 月付推算的房價區間。
- 挑戰：本次房價高於以月收入 40% 月付推算的房價上界。

跑道的本次房價標記必須限制在軌道範圍內。房價超出視覺刻度時，標記固定於最左或最右端，文字仍顯示實際房價與判斷結果。

### 互動方式

- 第 3 步保留家庭月收入輸入與既有收入滑桿，但不再顯示可負擔房價結果卡。
- 最後一頁的跑道加入家庭月收入滑桿，初始值沿用第 3 步輸入。
- 使用者拖動結果頁滑桿時，即時更新舒適購屋帶、建議月付、區域判斷與房價標記。
- 結果頁滑桿同步第 3 步的收入輸入與滑桿，返回上一頁時可看到相同數值。
- 收入模擬只更新購屋預算跑道，不重新計算貸款本金、利率、期數或主月付結果。
- 收入為 0 時顯示：「填入家庭月收入，就能看看這間房落在哪個負擔區間。」並隱藏無效跑道數值。

## 精靈導覽按鈕

套用到房地合一稅、買方費用、貸款計算與青安貸款 3.0：

- 中間步驟同時有上一步與下一步時，使用兩個等寬欄位，各占 50%。
- 兩個按鈕使用相同高度與最小觸控尺寸。
- 最後一頁將「重新調整」統一改為「上一頁」。
- 最後一頁只有「上一頁」時，按鈕橫跨整排。
- 「上一頁」回到精靈的上一個步驟，不使用瀏覽器歷史返回。
- 結果內的「重新試算」維持原意：清除目前計算器資料並重新開始。

## 視覺與響應式規則

- 沿用目前台南小魏的深藍、磚紅、米白品牌色。
- 跑道使用低飽和綠、金、磚紅區分安心、剛好、挑戰，不以警告圖示製造焦慮。
- 手機寬度 360px 時，跑道文字、房價標記與收入控制不得造成橫向溢位。
- 桌機 1436px 時，結果資訊維持目前雙欄節奏，跑道可橫跨完整結果寬度。
- 收合明細的摘要列需有清楚的展開符號與鍵盤焦點樣式。

## 無障礙與錯誤處理

- 收入滑桿具備可辨識的 `aria-label`。
- 跑道狀態不能只靠顏色，必須同時顯示安心、剛好或挑戰文字。
- `<details>`／`<summary>` 可用鍵盤開合，並保留可見焦點。
- 非數字、空值或負數收入一律視為 0，顯示提示而不產生 `NaN`、無限值或腳本錯誤。
- 舊的儲存收入值繼續沿用，不建立新的資料格式或遷移版本。

## 測試與驗收

### 自動測試

- 一般貸款結果不存在「總利息與月付範圍」、「最高月付」與「最低月付」。
- 一般貸款與青安主表不存在可見的利息欄。
- 兩個結果頁都存在預設收合的「查看總成本明細」，且包含應保留的總利息與分段利息。
- 第 3 步不再輸出可負擔房價結果卡，最後一頁存在購屋預算跑道。
- 結果頁收入滑桿與原收入欄位同步。
- 所有精靈最後一步不再出現「重新調整」。
- 按鈕等寬、等高，單一上一頁能橫跨整排。

### 瀏覽器驗收

- 360×800 與 1436×1320 兩種視窗皆無頁面橫向溢位。
- 測試安心、剛好、挑戰三種房價位置。
- 拖動結果頁收入滑桿後，房價區間、月付範圍、區域文字與標記同步更新。
- 展開總成本明細可看到利息資料，預設載入時保持收合。
- 上一頁可回到正確步驟，重新試算仍會清除資料。
- 瀏覽器主控台無錯誤。
