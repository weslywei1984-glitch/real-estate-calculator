# 功能雙色結果卡與公告現值工具重設規格

日期：2026-08-04  
狀態：等待使用者書面確認

## 目標

改善房地合一稅與一般房貸結果主卡的配色，使兩種工具一眼可辨識，同時保留台南小魏既有的米白、深色文字與陶土色品牌語彙。重新整理 `tainan-land-value-helper.html` 頭部以下的查詢工作區，降低空洞感並建立清楚的三步查詢流程。

本次只改變視覺層級、排版與響應式呈現，不變更計算公式、查詢流程、欄位意義、儲存資料、複製、下載或頁面跳轉行為。

## 核定方向

採用 B「功能雙色」：

- 房地合一稅：陶土紅主卡。
- 一般房貸：深湖藍主卡。
- 公告現值工具：左側三步查詢任務，右側結果儀表板。
- 頁首主視覺不修改。

## 色彩系統

新增或整理為共用語意色票，避免在元件內散落任意色碼：

- 稅務主色：`#8E402B`。
- 貸款主色：`#164D5C`。
- 品牌陶土強調：`#C95832`。
- 深色文字：`#102B38`。
- 紙張米白：`#F7F0E2`。
- 卡片白：`#FFFDF8`。
- 金砂數字：`#FFE0A8`；僅用於深色主卡的核心金額。
- 淺藍結果底：`#DCEBF0`。
- 淺陶土輸入底：`#F5EADC`。

文字與背景組合需維持 WCAG AA 對比；深色主卡上的次要文字不得只靠降低透明度到難以閱讀。

## 房地合一稅結果主卡

保留既有 `.tax-result-hero` 的全寬、雙欄結構與內容順序：

1. 左側為「預估應納房地合一稅」與核心金額。
2. 右側為「適用稅率」、百分比與稅率情境說明。

視覺調整：

- 背景由目前共用深藍改為陶土紅。
- 主金額與稅率使用金砂色；標籤與情境文字使用高對比米白。
- 雙欄中間保留低對比垂直分隔線。
- 卡片上緣沿用細陶土品牌線，但不得與背景融在一起。
- 手機版維持上下堆疊，分隔線改為水平線。

計算明細、自住優惠檢核與申報提醒的資料與排列不變。

## 一般房貸月付主卡

保留既有 `.loan-payment-hero`、期數徽章與有／無寬限期兩種分支：

- 有寬限期：顯示寬限期月付與寬限期後月付兩欄。
- 無寬限期：只顯示單一「每月月付」，不得留下空白欄位。

視覺調整：

- 背景改為深湖藍。
- 月付金額使用金砂色，標籤與說明使用高對比米白。
- 期數徽章使用透明淺框，不新增另一張期數卡。
- 前後月付分隔線使用低對比淺色線。
- 手機版維持上下堆疊，分隔線轉為水平線。

四張購屋摘要卡、購屋預算跑道、攤還表與總成本收合明細的內容與行為不變。

## 公告現值工具工作區

### 頁首

`tainan-land-value-helper.html` 既有品牌主視覺與工具標題區完全保留，不調整圖片、標題、說明與頁首高度。

### 桌機架構

頭部以下維持兩欄，但重新定義欄位責任：

- 左欄約 56%：三步查詢任務。
- 右欄約 44%：結果儀表板，維持合理的 sticky 行為。

左欄以三個連續步驟分組：

1. 選擇行政區與小段。
2. 輸入地號母號與子號。
3. 確認土地面積、坪數與前次移轉現值。

每一步都有圓形步驟編號、短標題與對應欄位；現有欄位 ID、選項、預設值、提示與換算關係全部保留。公告現值與公告地價的資料狀態改成同一步中的緊湊資訊列，不再形成兩張高度過大的空白卡。

查詢按鈕固定放在第三步尾端，與主要流程對齊。既有「只有門牌先查地號」入口保留，但調整為次要按鈕，不與主要查詢按鈕競爭。

### 結果儀表板

右欄由目前等高堆疊卡改為：

1. 深湖藍主結果：公告現值坪數換算。
2. 兩張淺色次結果：前次移轉現值坪數換算、土地價格差額。
3. 一張緊湊補充結果：每坪公告土地現值。
4. 查詢摘要收合區。
5. 複製、下載與返回其他計算器的操作列。

主結果使用深湖藍，次結果交替使用淺藍與米白，避免四張卡都同樣白而失去層級。查詢前、查詢中、成功與錯誤狀態仍由既有 `data-state` 控制，僅調整視覺呈現。

### 手機架構

在 640px 以下改為單欄：

1. 三步查詢任務。
2. 結果儀表板。
3. 查詢摘要與操作按鈕。

右欄取消 sticky。步驟編號、輸入欄位與按鈕不得造成整頁水平捲動；操作按鈕維持至少 44px 高。結果卡在 360px、375px 與 390px 寬度都需完整顯示。

## 動態與互動

- 保留既有輸入同步、查詢、資料狀態、複製、JPG 下載與頁面連結。
- 僅使用短距離淡入與數值更新提示，不新增長時間或循環動畫。
- `prefers-reduced-motion: reduce` 時停用非必要動畫。
- Hover 只作為桌機加強，所有核心功能必須可用鍵盤與觸控操作。

## 相容性與資料邊界

- 不更動任何輸入欄位 ID、表單事件、API 路徑或 localStorage key。
- 不修改公告現值資料查詢與換算公式。
- 不修改房地合一稅與一般房貸計算公式。
- 不修改複製摘要、產圖或跨頁連結所依賴的 DOM 資料內容；若調整容器階層，需同步維持摘要擷取契約。
- 不修改 `land-increment-total.html`。

## 測試與驗收

### 自動化

- 現有完整測試套件必須維持全數通過；目前基準為 113 項。
- 新增結果主卡語意色與公告現值工作區結構契約測試。
- 驗證查詢欄位、資料狀態、複製與下載相關選擇器仍存在。
- 執行 `git diff --check`。

### 瀏覽器

以本機 HTTP 頁面驗證：

- 1436×1320：稅務陶土紅、貸款深湖藍；公告現值為左右工作台。
- 390×844、375×812、360×800：兩張結果主卡正確堆疊；公告現值工具為單欄。
- 分頁字級維持桌機 16px、手機 14px，觸控高度 48px。
- `document.documentElement.scrollWidth <= document.documentElement.clientWidth`。
- 瀏覽器 console 無 error。

### 不在本次範圍

- 不重新設計頁首主視覺。
- 不調整青安與買方費用結果頁配色。
- 不新增後端或第三方服務。
- 不在規格階段推送或發布網站。
