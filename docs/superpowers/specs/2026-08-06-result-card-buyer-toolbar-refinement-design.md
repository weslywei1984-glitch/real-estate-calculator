# 結果主卡、買方欄位與土地工具列精修設計規格

## 目標

依照使用者在公開頁面上的八則標註，改善房地合一稅結果主卡、買方費用第二步欄位，以及土地漲價工具操作列的視覺密度、文案與排列方式。所有既有計算公式、欄位 ID、輸入單位、儲存資料與事件行為維持不變。

## 核准配色

採用 C「湖水活力」方向：

- 主色：湖水深綠 `#164D5C`。
- 重點色：琥珀色 `#E0A63B`。
- 高亮文字：暖米白 `#FFF0C8`。
- 一般淺色表面：既有奶油白 `#FFFAF0`。
- 深色文字：既有深海軍藍 `#102738`。

## 房地合一稅結果主卡

- 將 `.tax-result-hero` 從整片陶土紅改為湖水深綠背景。
- 稅額與稅率數字使用暖米白；主卡頂部以琥珀色細線建立辨識度。
- 桌機維持左右兩欄：左側稅額、右側適用稅率。
- 降低上下留白，讓卡片內容垂直置中並縮短主卡高度。
- 手機維持單欄；第二區塊改用上分隔線，不產生橫向溢位。
- 預估稅額文字在現有萬元格式前加入「約」，例如 `約 90 萬`。
- 計算明細、自住資格、提醒內容與稅率邏輯不更動。

## 買方費用第二步

### 欄位順序

桌機兩欄依序排列：

1. 左欄：房屋評定現值／契價。
2. 右欄：抵押權設定金額倍率。
3. 下一列左欄：土地申報地價總額。
4. 查詢連結維持跨兩欄。

手機仍依相同語意順序直向排列。

### 文案

- 房屋評定現值提示改為：`填房屋稅單的「課稅現值」`。
- 土地申報地價提示改為：`填公告地價 × 持有面積（m²）`。
- 查詢提示改為：`查完資料後回填－土地申報地價總額`。
- 抵押權設定倍率的選項顯示文字：
  - `1.2` 顯示為「銀行貸款」。
  - `0` 顯示為「不用貸款」。
- 隱藏欄位 `mortgageSettingRatio` 的值仍為 `1.2` 或 `0`，不變更計算方式。

## 土地漲價工具操作列

- 操作列保留四個既有動作與 ID／連結：清空、套用範例、回稅費與貸款試算、用地號查公告現值。
- 桌機與平板寬度將四個按鈕固定在同一排，使用四欄網格，較長的兩個導覽按鈕取得較多寬度。
- 手機窄寬度改為兩欄、兩排，保留至少 44px 的觸控高度及可讀字級。
- 配色統一為湖水深綠、琥珀色、米白與深海軍藍：
  - 清空：米白底、深海軍藍框線與文字。
  - 套用範例：琥珀色底、深海軍藍文字。
  - 回稅費與貸款試算：米白底、湖水深綠框線與文字。
  - 用地號查公告現值：湖水深綠底、米白文字。
- 不改變按鈕事件、連結位置、載入狀態、成功狀態或鍵盤操作。

## 響應式與無障礙

- 驗證桌機 `1054 × 1014`，對應使用者標註畫面。
- 驗證手機 `390 × 844`、`375 × 812`、`360 × 800`。
- 所有尺寸不得出現水平捲動。
- 按鈕、欄位與選項保留既有鍵盤焦點樣式與至少 44px 觸控高度。
- 配色文字對比須維持清楚；資訊不只依賴顏色傳達。

## 測試策略

- 先新增來源契約測試，確認新配色、`約` 前綴、買方欄位順序、精簡文案與新選項文字。
- 先新增土地工具列測試，確認桌機四欄單排與手機兩欄配置。
- 逐項確認測試在修改正式頁面前失敗，再做最小實作使其通過。
- 執行完整 `npm.cmd test` 與 `git diff --check`。
- 透過本機 HTTP 預覽，在指定桌機與手機尺寸檢查版面、橫向溢位及瀏覽器錯誤。

## 不在本次範圍

- 不修改房地合一稅、買方費用或土地漲價的任何公式。
- 不更動萬元／元輸入與舊資料遷移。
- 不更換頁首、導覽列、聯絡按鈕或其他計算器結果卡。
- 不直接發布；完成實作與驗證後再依使用者指示處理發布。
