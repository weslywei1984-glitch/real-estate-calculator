# 手機版限定修正設計

**日期：** 2026-07-31  
**專案：** real-estate-calculator

## 目標

保留本次 B 版「品牌顧問風」的手機介面與四步驟操作，但桌機版恢復 2026-07-31 改版前的原始外觀。同步修正手機版貸款利率預設值與底部參考資料排版。

## 已確認範圍

### 1. 只在手機套用 B 版設計

- B 版配色、頁首、卡片、分頁與四步驟視覺限定於 `max-width: 620px`。
- 桌機與平板寬度大於 620px 時，沿用既有基礎樣式，不套用 B 版全域主題。
- 手機四步驟所需的標題、進度、前後步驟按鈕與結果操作按鈕在桌機維持隱藏。
- 桌機仍保留原本的雙欄表單與結果區，不因手機步驟狀態隱藏內容。

### 2. 貸款計算年利率預設 2.5%

- `annualRate` HTML 預設值與程式預設值維持 `2.5`。
- 新增一次性的儲存資料版本遷移：舊版 localStorage 尚未記錄此版本時，首次載入新版會將一般貸款年利率套回 `2.5`。
- 遷移完成後仍尊重使用者自行修改的年利率，不在每次載入時強制覆寫。
- 清空一般貸款表單後，年利率回到 `2.5`。

### 3. 手機底部參考資料條列化

- 將「計算依據」內容整理成語意化清單，每一類來源各自一項。
- 手機版使用清楚的圓點、行距、項目間距與連結換行，避免所有文字黏成一段。
- 桌機版清單維持原本的橫向段落外觀，不增加大型間距或改變既有版面高度。
- 政府來源、連結網址與免責內容完全保留，不修改政策資訊。

## 明確排除

- 本次不處理「購買總價」在貸款計算或青安結果頁的顯示位置。
- 不修改稅率、貸款公式、青安政策數字、買方費用公式或 LIFF 好友鎖。
- 不新增獨立手機頁面、外部框架或後端服務。

## 實作方式

1. 保留全域的手機步驟元件隱藏規則。
2. 將 Consultant B 主題的視覺規則包在 `@media (max-width: 620px)` 中。
3. 對參考資料加入結構化清單標記，桌機使用行內顯示，手機改為垂直條列。
4. 在 localStorage 資料中加入年利率預設版本，舊資料只遷移一次。

## 驗證

- 自動測試確認 Consultant B 主題只存在於手機媒體查詢。
- 自動測試確認桌機不會套用手機步驟隱藏與結果表單隱藏規則。
- 自動測試確認 `annualRate` HTML、程式預設值與舊資料遷移皆為 `2.5`。
- 自動測試確認參考資料為多項清單，且手機條列樣式只在 `620px` 以下生效。
- 瀏覽器驗證 375×812 與 390×844：四步驟可操作、年利率為 2.5、來源條列清楚、無水平溢位。
- 瀏覽器驗證 1280×800：桌機外觀與改版前一致，表單與結果雙欄同時顯示。
- 四個計算器皆可完成試算，console 無錯誤。
