# 房地稅費與貸款試算品牌化 UI 改版設計

## 目標

將現有計算器從墨綠、金色、重光暈的金融活動頁風格，改為與 `https://tainanwei.com/` 一致的「深海軍藍、暖米白、陶土橘」品牌風格，同時保留工具需要的清楚、緊湊與可信度。

本次只調整視覺與排版，不變更四個計算器的欄位、公式、驗證、結果內容、按鈕功能、localStorage、網址 hash、LIFF 好友鎖或免責聲明。

## 設計方向

採用「品牌配色 + 工具型排版」，而不是直接複製品牌首頁：

- 延續品牌首頁的深海軍藍、暖米白、陶土橘與襯線標題。
- 表單維持高資訊密度，不使用品牌首頁的大面積留白。
- 降低圓角、漸層、發光與浮誇陰影，建立較安靜的顧問感。
- 用色塊、細線、字重與數字大小建立層級，不依靠大量裝飾。
- 四個計算器共享同一套視覺系統，青安方案只保留必要的政策辨識。

## 視覺系統

### 色彩

```css
--brand-navy: #102738;
--brand-navy-strong: #0b1f2c;
--brand-cream: #f4efe5;
--brand-paper: #fffdf8;
--brand-terracotta: #b94f2c;
--brand-terracotta-dark: #963f24;
--brand-ink: #2d2b28;
--brand-muted: #6f6a62;
--brand-line: #d8d0c3;
--brand-success: #176b5b;
--brand-warning: #9a621e;
--brand-error: #a33b32;
```

- 頁面主背景以暖米白為主，不再使用斜切雙色背景。
- 深海軍藍用於頁首、分頁導覽、重要結果與頁尾。
- 陶土橘只用於主要操作、選中狀態、重點數字或細線。
- 成功、警告、錯誤保留語意色，不強制套用品牌橘。
- 金色只保留在人像領帶或既有圖片內，不再作為主要 UI 色。

### 字體

- 大標題與重要區塊標題：`Noto Serif TC`。
- 表單、說明、按鈕、數字：`Noto Sans TC`。
- 金額維持黑體與高字重，避免襯線數字降低辨識。
- 不新增外部 CDN；沿用目前可用的字體堆疊與系統備援字體。

### 形狀與陰影

- 主要卡片圓角：`10px` 至 `14px`。
- 輸入框與次要卡片圓角：`8px` 至 `10px`。
- 標籤型內容才使用膠囊形狀。
- 移除金色厚邊框、玻璃光暈與大面積漸層。
- 陰影改為低透明、短距離陰影，主要靠邊框區分層級。

## 頁面結構

### 品牌頁首

- 以 HTML/CSS 重建頁首，停止把完整標題、聯絡資訊與資料基準日期烙在單張主視覺圖內。
- 沿用現有透明人物素材 `assets/xiaowei-profile.png`，不重新生成或修改人物照片。
- 桌機版以深海軍藍容器承接文字與人物，移除金框、房屋插圖與發光效果。
- 資料基準改為可維護的 HTML 文字；日期代表內容校訂基準，不自動冒充每日最新資料。
- 手機版縮短頁首高度，確保進站後能快速看到分頁與第一個欄位。
- 不新增導覽列、諮詢 CTA 或其他首頁功能。

### 計算器分頁

- 桌機版維持四等分水平分頁。
- 選中項目使用陶土橘色塊或底線，未選中項目維持深藍底白字。
- Hover 只做色彩與邊框轉換，不做浮起或強光。
- 手機版維持單列並允許水平滑動，每個分頁顯示完整文字。

### 表單區

- 維持左表單、右結果的雙欄結構。
- 表單卡片改成暖白底、細灰邊框與較小圓角。
- 區塊標題使用深藍字與陶土橘短線，移除金色漸層表頭。
- 輸入框白底、深色文字，focus 使用陶土橘外框。
- 單位文字降低對比但保持可讀，金額欄位仍維持「萬元」等現有單位。
- Checkbox 卡片改成扁平列式，勾選後以淡暖色背景提示。

### 操作按鈕

- 主要操作使用陶土橘底、白字。
- 次要操作使用透明或暖白底、深藍邊框。
- Loading、success、error 保留既有文字與功能，只改視覺。
- Hover、active、focus-visible 都要有清楚但克制的狀態。
- 手機版按鈕可換行，但每個按鈕仍需保有至少 44px 點擊高度。

### 結果區

- 初始狀態使用淡米白虛線框，文案完全保留。
- 主要試算結果使用深海軍藍底、白色大數字與陶土橘細線。
- 次要結果使用白底、細邊框，不再每張卡片都加陰影。
- 成功、資格符合使用綠色；警告與不符合使用語意色。
- 計算明細與表格加強列間距、數字對齊與手機橫向閱讀。
- 結果卡片可保留 hover，但僅做邊框或背景變化，不位移。

### 青安貸款 3.0

- 青安政策摘要使用品牌深藍，不再使用獨立的青綠漸層風格。
- 政策數字用 2x2 緊湊網格，手機版避免四項垂直堆疊。
- 資格核對、貸款與自備款計算邏輯完全不變。
- 政策提醒仍保留正式方案與銀行核定免責資訊。

## 響應式規則

### 桌機

- 最大內容寬度約 `1180px` 至 `1240px`。
- 表單與結果欄比例約 `1.35fr / 0.85fr`。
- 主要資訊保持在首屏可見範圍，減少無效空白。

### 平板

- 於約 `900px` 以下切換單欄。
- 結果區接在表單後方，分頁保持可見。
- 表單欄位仍可維持兩欄，視欄位文字長度調整。

### 手機

- 以 `375px` 為主要驗證寬度。
- 頁面左右留白約 `14px` 至 `16px`。
- 表單改為單欄；按鈕與結果不得水平溢出。
- 頁首、政策摘要、卡片內距都比桌機縮小。
- 不以縮小字體作為唯一壓縮方式，優先減少裝飾與空白。

## 互動與可用性

- 保留現有按鈕、驗證、loading、success、error 與空狀態流程。
- 所有互動 transition 控制在 `160ms` 至 `220ms`。
- 支援 `prefers-reduced-motion`，停用非必要動畫。
- Focus 狀態必須可見，不以 hover 取代鍵盤操作提示。
- 一般文字與背景對比至少符合 WCAG AA。
- 金額、稅率、期數等結果不可只靠顏色傳達狀態。

## 技術實作邊界

- 繼續維持單一 `index.html`，不拆 CSS 或 JS。
- 在現有最後一層 IMAGE2 主題後新增一層品牌主題覆寫；本次不清理舊主題，以降低功能回歸風險。
- 不引入外部框架、CSS library 或 CDN。
- 除頁首需由靜態圖片改為可維護內容外，不修改計算器的既有 DOM 結構。
- 不處理 `tainan-land-value-helper.html` 與 `land-increment-total.html` 的視覺改版；本輪只處理主頁四個計算器。

## 驗收標準

1. 四個計算器的公式、預設值、清空、套用範例、複製結果與存成圖片功能不變。
2. 桌機版與 `tainanwei.com` 明顯屬於同一品牌系統。
3. 手機版 `375px` 無水平捲動、欄位截斷或按鈕重疊。
4. 首屏高度比目前版本更短，使用者能更快看到第一個輸入欄位。
5. 四個計算器都能產生成功結果，空狀態與錯誤狀態正常。
6. Console 無錯誤。
7. 完整測試套件通過。
8. 正式部署後以實際網址再次驗證桌機與手機。

## 不在本次範圍

- 不新增計算器、比較功能、案例、FAQ 或行銷模組。
- 不修改政策數字、稅率、公式與政府來源。
- 不更換或重新生成透明人物照片。
- 不修改 LIFF 好友鎖、外部連結或部署架構。
