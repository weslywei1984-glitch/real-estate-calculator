# 房貸與房地合一稅整合式結果儀表板設計

## 目標

消除房貸結果與房地合一稅結果在桌機版出現的大片空白，將相互關聯的數據整合成有明確層級的主卡與摘要卡。計算公式、輸入欄位、稅率判斷、金額格式、購屋預算跑道與既有品牌色不變。

## 設計方向

採用「整合式結果儀表板」。不以增加說明文字填滿空間，而是重新組合現有資訊：主要決策數字集中在主卡，次要條件集中在等寬摘要卡，明細區塊維持全寬。視覺沿用台南小魏的深藍、磚紅、米白顧問風格。

## 房貸結果

### 月付主卡

1. 將目前分開的寬限期月付與寬限期後月付合併成一張全寬「每月還款節奏」主卡。
2. 有寬限期時，主卡在桌機顯示兩個等寬區塊：
   - 寬限期月付。
   - 寬限期後月付。
3. 沒有寬限期時，只顯示一個「每月月付」區塊並占滿主卡，不保留空欄。
4. 貸款總期數以右上角狀態標籤顯示，例如「360 期」，不再占用獨立半欄卡片。
5. 月付金額、寬限期判斷與還款試算邏輯完全不變。

### 購屋摘要卡

1. 月付主卡下方顯示四張等寬摘要卡：
   - 房屋成交總價。
   - 自備款。
   - 貸款本金。
   - 實際貸款成數。
2. 桌機四張同排；手機使用 2×2 排列。
3. 摘要卡只重組既有數字，不增加新計算。

### 其餘結果

- 購屋預算跑道維持全寬並保留互動滑桿。
- 還款期數表格維持全寬。
- 「查看總成本明細」維持預設收合與全寬。
- 複製結果、存成圖片與重新試算功能不變。

## 房地合一稅結果

### 稅額主卡

1. 將「預估應納房地合一稅」與「適用稅率」整合為一張全寬主卡。
2. 主卡左側顯示預估稅額；右側顯示：
   - 適用稅率百分比。
   - 既有稅率情境說明，例如「自住房地優惠：超過 400 萬部分 10%」。
3. 移除目前會被計算明細高度強制撐大的獨立半欄稅率卡。
4. 稅額、適用稅率與情境文字的計算邏輯完全不變。

### 明細與資格

- 計算明細改為全寬，所有項目、金額與順序不變。
- 自住優惠檢核與申報提醒維持全寬。
- 既有資格條件、狀態文字與稅務提醒內容不變。

## 響應式設計

- 桌機版房貸月付主卡使用雙欄、摘要卡使用四欄。
- 手機版月付主卡改為單欄，摘要卡使用 2×2。
- 房地合一稅主卡在桌機左右排列、手機上下排列。
- 360px、375px、390px 均不得產生頁面橫向捲動。
- 既有四個計算器分頁維持桌機 16px、手機 14px 與至少 48px 點擊高度。

## 可及性與限制

- 主卡內容使用文字標籤，不只依賴顏色表達資訊。
- 金額與狀態文字允許自然換行，但主要數字不可被裁切。
- 不新增第三方套件、遠端字型、動畫或稅務建議。
- 不修改 localStorage、表單流程、輸入預設值或試算資料。

## 驗收標準

1. 房貸結果不再出現「期數只占左欄、右欄空白」或其他半欄空洞。
2. 有寬限期時兩個月付並列於同一主卡；無寬限期時只顯示一個全寬月付。
3. 房價、自備款、貸款本金與貸款成數形成四張整齊摘要卡。
4. 房地合一稅不再顯示獨立半欄稅率卡；稅額與稅率在同一主卡。
5. 所有原有金額、期數、稅率、資格狀態、表格與收合明細內容不變。
6. 自動化測試、`git diff --check`、1436px 桌機與 360／375／390px 手機瀏覽器驗證通過，且瀏覽器主控台無錯誤。
