# 統一試算工具視覺與結果格式設計

**日期：** 2026-08-02

**狀態：** 使用者核定方案 A

**範圍：** `index.html`、`tainan-land-value-helper.html`、`land-increment-total.html` 與相關回歸測試

## 目標

把「台南公告土地現值查詢」與「土地漲多少計算器」完整移植到 4 合 1 計算器已核定的品牌視覺系統，同時依瀏覽器標註整理青安、房地合一稅、買方費用與貸款結果。既有公式、政策條件、資料來源、公開網址與主要操作流程保持不變。

## 設計方向

採用方案 A：完整視覺移植、功能原地保留。

- 兩個土地工具沿用各自的查詢與計算流程，不新增主頁分頁，也不硬改成四步驟精靈。
- 三個公開頁面使用同一套品牌語言：核定主視覺、奶油底色、深藍資訊層、陶土色主要行動、米白紙張卡片、細邊框與克制陰影。
- 桌機維持置中寬版工作區；手機轉成單欄並保留固定電話／LINE 聯絡列。
- 不新增外部框架或 CDN；三個頁面仍可由 GitHub Pages 直接使用。

## 土地工具視覺移植

### 共用品牌契約

`tainan-land-value-helper.html` 與 `land-increment-total.html` 都要使用以下視覺契約：

- 頁首顯示 `assets/mobile-hero-exact.jpg`，圖片維持 1787×880 原始比例，不裁切、不重製。
- 核心色票與主頁 Consultant B 一致：奶油 `#f3ead7`、深藍 `#102738`、陶土 `#b9502d`。
- 工作區最大寬度與主頁一致，桌機使用約 1040px 置中內容寬度。
- 表單、結果、說明與來源區塊使用相同圓角、邊框、標題層級、按鈕高度與鍵盤焦點樣式。
- 桌機聯絡列進入頁面主流程；620px 以下維持固定於畫面底部，並保留內容底部安全距離。
- 支援 `prefers-reduced-motion`，所有互動目標至少 44px 高。

### 公告土地現值查詢頁

- 保留行政區、小段、地號整理、公告現值靜態資料、前次移轉現值手動輸入、摘要複製與圖片功能。
- 頁首舊有深綠文字橫幅改成核定品牌主視覺。
- 輸入區與換算結果改成同一個置中工作區；桌機可採輸入／結果雙欄，窄螢幕單欄。
- 查詢狀態、錯誤、空值與成功狀態只換視覺，不改既有資料流。
- 官方查詢、回到 4 合 1 與土地漲多少的連結保留原目的地。

### 土地漲多少計算器

- 保留「用公告現值算／我已經有總額」模式、所有公式、扣除成本、摘要複製及圖片下載。
- 舊有格線背景與多色卡片改成品牌奶油底、深藍結果主卡與陶土主要按鈕。
- 桌機維持輸入／結果雙欄，手機單欄；結果卡仍可固定於桌機視野，但不得遮擋內容。
- 回到 4 合 1 與公告現值查詢的連結保留。

## 青安結果版面

### 總貸款與自備款

- `預估總貸款` 與 `預估自備款` 使用兩張等寬、等層級的大型摘要卡，固定排在同一列。
- 此摘要列有自己的版面規則，不再讓 `.young-main` 單獨跨越桌機兩欄。
- 360px 手機仍維持兩欄；數字使用 `clamp()` 縮放並允許卡片內文字壓縮，不造成水平頁面溢出。
- 若存在青安額度拆分說明，說明卡緊接在兩張摘要卡下方並跨滿整列。
- 若沒有拆分說明，兩張摘要卡仍維持大型樣式，不留下空白說明卡。

### 拆分貸款說明

- `貸 1,600 萬，超過……` 的文字從獨立結果欄位置移到摘要列正下方。
- 文字內容、一般房貸 2.5% 假設與提醒保持不變，只改位置與視覺層級。

### 月付算式

- 青安寬限期月付與寬限期後月付的算式各自保持單行，例如 `$14,792 + $19,787 = $34,579`。
- 算式容器使用不換行與響應式字級；手機不得拆成兩行，也不得造成整頁水平溢出。
- 青安金額的陶土色標記與「後」字強調保留。

### 五階段表格

- 移除表格外獨立的 `<h3 class="table-title">`。
- `青安－五階段利率與月付` 改成表格內的語意化 `<caption>`，視覺上貼合表格頂部。
- 表格欄位、五個階段、利率與計算內容不變；窄螢幕仍可在表格容器內水平捲動。

### 結果返回按鈕

- 青安結果第 4 步的返回按鈕文字改為 `上一頁`。
- 青安第 1～3 步與其他計算器既有 `上一步`／`重新調整` 行為不變。
- 點擊後回到青安第 3 步並保留已輸入資料。

## 金額輸入與輸出

### 房地合一稅

- `取得、改良與移轉費用`、`土地漲價總數額` 改用萬元輸入，加入 `data-money-unit="wan"`，單位文字改成 `萬元`。
- 計算引擎仍以元運算；`value()` 負責把萬元乘以 10,000。
- `預估應納房地合一稅` 與「計算明細」內所有金額改用萬元顯示，不再使用 TWD `$` 格式。
- 顯示範例：`900,000 元` → `90 萬`、`20,000,000 元` → `2,000 萬`、`-5,000,000 元` → `-500 萬`。
- 稅率、免稅額與公式完全不變。

### 買方費用

- `房屋評定現值／契價`、`土地申報地價總額` 改用萬元輸入。
- 預設畫面值分別由 `1,000,000`、`1,800,000` 改為 `100`、`180`，程式內預設值仍表示 1,000,000 與 1,800,000 元。
- 契稅、印花稅、登記規費與仲介服務費公式不變。

### 貸款結果

- 只修改使用者標註的「總利息與月付範圍」摘要及攤還表格金額；其他結果卡保持既有單位與結構。
- 新增單一格式函式：先將正數無條件進位到最接近的 1,000 元，再除以 10,000 顯示為萬，前綴 `約`。
- 顯示範例：`5,069,223 元` → `約 507 萬`；`47,415 元` → `約 4.8 萬`；`12,000,000 元` → `約 1,200 萬`；`0 元` → `約 0 萬`。
- 範圍的兩端要分別套用相同規則，再組成 `約 X～Y 萬`；不得先合併範圍再進位。
- 計算精度與攤還公式不變，格式化只發生在輸出階段。

## 舊資料遷移

- localStorage 仍使用 `realEstateCalcInputs.v1`，新增明確的萬元欄位版本，例如 `__moneyUnitVersion: 3`。
- 從版本 2 還原資料時，只把四個新改萬元欄位除以 10,000：`sellExpense`、`landGain`、`buildingValue`、`landDeclaredValue`。
- 已是版本 3 的資料不得再次轉換；其他既有萬元欄位與貸款成數遷移邏輯不受影響。
- 清空、重設與頁面初次載入都要顯示新單位下的正確值。

## 錯誤處理與可用性

- 不變更三頁既有輸入驗證、查詢錯誤提示、資格檢核與免責聲明。
- 新格式函式要處理非有限數字、負數與零；畫面不得出現 `NaN`、`Infinity` 或 `-0 萬`。
- 所有新增版面在 360px 寬度不得造成整頁水平捲動。
- 鍵盤焦點、ARIA 標籤、表格 caption 與按鈕語意保持可讀。
