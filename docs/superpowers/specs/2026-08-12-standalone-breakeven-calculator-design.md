# 平轉成本計算器獨立頁設計

日期：2026-08-12

## 目標

將「房屋平轉成本」從公開首頁的計算器分頁完全拆出，改為可直接開啟但不在公開導覽曝光的獨立頁面。

- 獨立網址：`https://calc.tainanwei.com/breakeven.html`
- 不要求登入或密碼；知道網址的人仍可開啟。
- 公開首頁恢復四個計算器，不顯示或連結平轉工具。
- 獨立頁加入 `noindex`、`nofollow`、`noarchive`，降低搜尋引擎收錄機會，但不把它描述成安全存取控制。

## 頁面拆分

### 公開首頁 `index.html`

- 移除「平轉成本」分頁、表單、結果區與 `#breakeven` hash 路由。
- 移除只供平轉工具使用的樣式、預設值、事件監聽、計算器登錄、摘要複製、圖片輸出與精靈設定，避免留下不可達程式碼。
- 保留房地合一稅、買方現金需求、房貸月付與青安貸款四個既有計算器，其外觀、計算規則及已儲存資料保持相容。

### 獨立頁 `breakeven.html`

- 使用單一自包含 HTML，不新增外部套件、後端或 CDN。
- 沿用目前墨綠與金色的視覺語言，但不顯示其他計算器分頁，也不加入公開首頁入口。
- 保留既有四步驟流程：房屋資料、實際成本、出售與稅務、不賠結果。
- 保留快速／進階成本互斥、房地合一稅估算與手動覆寫、二分搜尋、萬元向上進位、建議開價、預想成交損益、實拿現金、每坪價格、資料完整度提示、清空、摘要複製與圖片分享。
- 保留「僅供估算，正式以稅務機關、地政士與實際契約核定為準」聲明及現有政府資料來源。
- 不載入公開頁匿名分析程式，避免個人試算污染公開使用統計。

## 資料與相容性

- 獨立頁改用 `realEstateBreakevenInputs.v1` 儲存資料，避免與公開四個計算器互相覆寫。
- 第一次載入且新 key 尚無資料時，從舊 `realEstateCalcInputs.v1` 的平轉欄位匯入一次；不修改或刪除舊 key。
- 匯入後只讀寫獨立 key。清空功能只清除獨立頁欄位，不影響公開四個計算器。
- 無法使用 localStorage 時仍可正常試算，只是不保留資料。

## 錯誤與邊界

- 日期顛倒、負值、仲介費超過 6%、議價率異常及求解失敗時停止計算並顯示明確錯誤。
- 2016 年以前取得或不適用房地合一稅 2.0 時，停用自動稅額並要求手動輸入。
- 缺少土地稅資料或憑證時仍可試算，但結果標示「資料尚未完整」。
- 剩餘房貸本金只影響實拿現金，不影響不賠價。

## 驗收

- 結構測試確認 `index.html` 僅有四個分頁，且沒有 `breakeven` 分頁、表單或 hash 路由。
- 獨立頁結構測試確認四步驟、完整欄位、獨立 localStorage、舊資料匯入、清空、複製與圖片功能存在。
- 原有平轉單元案例改為從 `breakeven.html` 載入純計算函式，既有數值與稅率邊界全部維持通過。
- 執行完整 `npm.cmd test`、JavaScript 語法檢查與 `git diff --check`。
- 本機 HTTP 驗證桌機與 375px 手機版、console、重新載入暫存及兩頁互不影響。
- 正式發布後確認公開首頁只有四個計算器，`/breakeven.html` 可直接開啟、帶有 noindex、沒有公開頁回連，且版本標頭與 release 一致。

## 不在本次範圍

- 不新增帳號、密碼或登入流程。
- 不建立子網域、資料庫或伺服器端儲存。
- 不改動既有四個計算器的公式、品牌內容或公開子工具。
