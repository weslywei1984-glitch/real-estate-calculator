# 土地漲多少計算器精簡設計

## 目標

依瀏覽器標註精簡 `land-increment-total.html`：移除頁首品牌膠囊、移除輸入欄位左側的步驟數字，並將結果說明改成「這塊土地估算漲了 X 萬」。

## 設計

- 刪除 `.brand-line` 的 HTML 與專用 CSS；保留標題與說明文字。
- 刪除兩種輸入模式全部 `.step-mark` 元素與專用 CSS，`.field-row` 改為單欄，欄位內容填滿卡片。
- 正數結果以萬元顯示，最多一位小數；例如 `5,920,000` 顯示「這塊土地估算漲了 592 萬」。零值與負值提示維持原邏輯。
- 不修改公式、輸入模式、欄位、結果明細、按鈕或其他頁面。

## 驗收

- 自動測試確認品牌膠囊與步驟標記不存在、欄位為單欄、結果文案符合指定格式。
- 完整測試通過後部署至 GitHub Pages，並以手機與桌機尺寸檢查正式頁面。
