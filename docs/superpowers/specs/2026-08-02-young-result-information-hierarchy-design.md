# 青安結果資訊層級調整設計

## 目標

讓使用者先看懂「房價、貸款、自備款與月付」，再閱讀長期利息與貸款拆分資訊。保留必要透明度，但避免長期總利息成為結果頁最醒目的勸退訊息。

## 核定版面

1. 青安結果最上方摘要改為三張等寬卡片，順序固定為：
   - 購屋總價
   - 預估總貸款
   - 預估自備款
2. 超過青安額度時的拆分貸款說明，移到三張摘要卡的下一排，橫跨整個摘要區寬度。
3. 青安寬限期前後月付維持目前主要視覺層級與單行算式。
4. 青安貸款試算區：
   - 將「預估總利息」改為「40 年預估總利息」，年數必須使用實際套用的貸款年限，不寫死 40。
   - 金額以次要明細樣式顯示為「約 X 萬」，沿用現有貸款摘要的千元進位規則，不改成主卡。
   - 移除「青安本息合計」，避免重複放大長期金額壓力。
5. 五階段利率與月付表格保留「利息」欄，讓需要深入比較的人仍可查看。

## 響應式規則

- 桌機與平板：三張摘要卡同一排；拆分貸款說明下一排全寬。
- 手機：三張摘要卡仍維持同一排，使用更緊湊的內距與自適應字級；不得產生頁面橫向捲動。
- 若 360px 下三張卡的文字可讀性不足，優先縮短標籤與調整字級，不改回多排。

## 計算與資料邊界

- 不修改青安資格、貸款額度、貸款拆分、利率、月付、總利息與攤還表公式。
- 「購屋總價」直接使用現有 `housePrice` 結果值。
- 總利息仍使用現有 `totalInterest`，以 `approxWanLine()` 顯示約數，只調整標籤與視覺層級。
- 不修改 localStorage 格式或既有輸入資料。
