# 結果卡資訊密度與分頁字級設計

## 目標

改善房地合一稅與買方費用結果頁的大面積空白，讓資訊層級更清楚、卡片高度更自然，同時放大四個計算器分頁文字。計算公式、欄位輸入、狀態判斷與既有品牌色不變。

## 設計方向

採用「精簡資訊卡」方向。結果頁維持台南小魏既有的深藍、磚紅與米白顧問風格，不新增裝飾性插圖，也不以大量說明文字填滿空間；改用較緊湊的版面配置、狀態標籤與清楚的資訊分組消除空虛感。

## 房地合一稅結果

1. 最上方「預估應納房地合一稅」維持全寬主結果卡。
2. 第二列保留「適用稅率」與「計算明細」兩個區塊：
   - 適用稅率以大型百分比、適用情境標籤與現有稅率說明組成完整的稅率摘要卡。
   - 計算明細保留目前所有金額與順序。
3. 「自住優惠檢核」改為全寬區塊，資格條件在桌機使用雙欄、手機使用單欄。
4. 原本獨立的「提醒」卡移除，現有合法支出憑證與正式申報提醒併入自住優惠檢核卡底部，呈現為一條緊湊提醒列。
5. 自住資格判斷、稅率、免稅額與稅額計算邏輯完全不變。

## 買方費用結果

1. 最上方「預估買方需準備現金」維持全寬主結果卡。
2. 「買方費用合計」改為全寬，保留所有費用項目、金額與順序。
3. 「稅務提醒」移至費用明細下方並改為全寬橫列。
4. 重購退稅與舊制財產交易所得各自呈現為一張小型提醒卡，包含標題與既有動態狀態文字：
   - 重購退稅維持「已提醒／未勾選」。
   - 舊制財產交易所得維持「後續個綜需檢查／目前未標記」。
5. 兩張提醒卡在桌機並排、手機堆疊；不新增稅務判斷或改變表單資料。

## 分頁列

1. 四個計算器分頁文字在桌機使用 16px、手機使用 14px。
2. 維持較明確字重、單行顯示與既有作用中狀態。
3. 點擊高度維持至少 48px，不因字級調整降低可操作性。
4. 360px、375px 與 390px 手機寬度不得產生頁面橫向捲動。

## 響應式與可及性

- 桌機版使用控制密度的兩欄與全寬區塊，不以固定高度強迫卡片等高。
- 手機版所有新增資訊卡轉為單欄，文字可自然換行，但分頁名稱保持單行。
- 狀態不只依賴顏色辨識，既有文字狀態必須保留。
- 不新增閃爍或高干擾動畫，維持既有鍵盤焦點與減少動態效果規則。

## 驗收標準

1. 房地合一稅結果不再出現獨立且大面積空白的提醒卡。
2. 買方費用結果不再以半欄等高卡片撐出大片空白。
3. 所有既有計算明細、資格狀態與提醒文字仍可見且數值不變。
4. 分頁文字在桌機與手機均明顯可讀，四個名稱維持單行。
5. 自動化測試、`git diff --check`、桌機 1436px 與手機 360/375/390px 瀏覽器驗證通過，且瀏覽器主控台無錯誤。
