# 房地稅費與貸款試算：手機設計完整移植桌機版

日期：2026-08-01

## 目標

將主頁目前只在 `620px` 以下啟用的「品牌顧問風」視覺與四步驟操作，延伸到平板與桌機。所有尺寸共用同一個內容順序、同一套色票、同一套卡片語言與同一個 wizard controller；桌機只透過較寬欄位、較大的留白與結果網格利用空間，不回到舊的一次展開表單或左右分割工作區。

本次只修改主頁 `index.html` 及其回歸測試。`tainan-land-value-helper.html`、`land-increment-total.html`、稅率、政策數字與計算公式均不在範圍內。

## 已核准的方向

- 手機、平板與桌機共用四步驟引導流程。
- 桌機採「共用寬版四步驟」，不是把 620px 窄畫面原封不動置中。
- 頁面維持手機版的上下閱讀順序；桌機在步驟內把合適欄位排成兩欄。
- 深海軍藍、陶土橘、奶油米色、灰綠、暖白卡片與細框陰影成為全尺寸唯一視覺主題。
- 手機版既有外觀與操作不得退步；桌機不再顯示舊的完整表單加右側即時結果。

## 頁首、分頁與主要寬度

### 頁首

- `assets/mobile-hero-exact.jpg` 成為所有尺寸唯一可見的頁首主視覺。
- 保持原始 `1787 × 880` 比例、`width: 100%`、`height: auto`；不得裁切、重壓縮、重新上色或另疊文字與人物。
- 原有 live hero 文字、人物與按鈕保留在 DOM 供回復與維護，但全尺寸不重複顯示。
- 圖片替代文字保留品牌、標題與服務資訊，避免純裝飾圖造成資訊缺口。
- 手機維持滿版呈現；桌機置於主內容寬度內，隨容器等比例放大。

- 手機維持目前約 `calc(100% - 20px)` 的內容寬度。
- `621px–900px` 使用單欄，內容上限約 760px。
- `901px` 以上使用置中的寬版單欄流程，內容上限約 1040px。
- 1920px 等寬螢幕增加左右留白，不拉長表單行長，也不重建左右工作區。

### 四個計算器分頁

- 四個分頁在所有尺寸都位於頁首下方並使用同一套暖白／陶土橘樣式。
- 手機維持可橫向操作的緊湊排列；桌機使用四等分橫列。
- 切換分頁仍更新 `#tax`、`#buyer`、`#loan`、`#young`，並回到該計算器第一步。

## 共用四步驟流程

### 顯示規則

- `.wizard-mobile-head` 與 `.wizard-mobile-actions` 改為全尺寸 wizard 元件；可以保留既有 class 名稱以縮小改動範圍。
- 所有尺寸同一時間只顯示目前的 `data-wizard-step`。
- 每一步都顯示 `01 / 04`、步驟標題、陶土橘進度條、上一步與下一步。
- 第三步的主要按鈕文字改為「查看結果」；第四步隱藏下一步並提供「重新調整」。
- 第四步隱藏表單，只顯示結果卡片、複製結果、存成圖片與重新調整。
- 步驟狀態只存在目前頁面，不寫入 localStorage 或 URL。

### 桌機排版

- wizard 標頭、表單卡片、操作按鈕與結果卡片依序垂直排列。
- 表單步驟在 `901px` 以上使用兩欄；標記為 `wide`、查詢提醒、核取清單與需要完整說明的區塊跨滿兩欄。
- `621px–900px` 固定使用單欄，避免標籤、單位或提示文字擠壓。
- 結果步驟使用同一張寬版卡片；主要數字全寬置頂，次要結果在桌機排成二至三欄，在手機回到單欄。
- 不保留桌機右側黏附結果欄，避免與分步流程同時出現兩種操作模式。

### 聯絡與來源

- 手機底部電話與 LINE 聯絡列保持不變。
- 桌機將同一組電話與 LINE 行動入口放在結果之後、來源之前的內容尾端操作列；不使用 fixed 定位，因此不會覆蓋 wizard 按鈕與結果。
- 政府來源在所有尺寸改用手機版的清楚清單語言；桌機可排成兩欄，但不再壓成分號相連的一行。
- 聯絡資訊固定使用魏泉承、台南小魏 買厝作伙、永慶不動產-小東南紡店、0927-617-207 與既有 LINE 目的地。

## 互動與程式結構

- 維持單一 `index.html`，不加入框架、CSS library、CDN 或新後端。
- 將 Consultant B 主題的共用規則移出 `max-width: 620px`；只把真正的尺寸差異留在 breakpoint 內。
- wizard controller 不再依 `WIZARD_MOBILE_QUERY.matches` 決定是否隱藏步驟或設定 `aria-hidden`，所有尺寸都以目前步驟為準。
- 點擊上一步、下一步、查看結果或重新調整後，焦點移到步驟標題，並讓標題回到可見區域；尊重 reduced motion。
- 下一步只檢查目前步驟既有的 HTML 限制，不新增或改寫政策判斷。
- 現有計算、千分位輸入、localStorage、清空、範例、複製、存圖與 hash 切換介面保持相容。
- 公開頁面不得重新載入 LIFF SDK 或 `assets/liff-gate.js`，Safari、Chrome 與 LINE 內建瀏覽器仍可直接使用。

## 錯誤與邊界狀態

- 欄位格式錯誤或超出既有限制時，停留在原步驟、顯示瀏覽器驗證訊息並聚焦第一個錯誤欄位。
- 無有效結果時沿用既有空狀態，不填入推測數字。
- 剪貼簿、圖片輸出與外部查詢失敗沿用既有錯誤處理。
- 視窗縮放或裝置旋轉時保留目前步驟與已輸入資料，不重設流程。
- 所有尺寸不得產生水平捲動、浮動聯絡列遮擋或頁首圖片裁切。
